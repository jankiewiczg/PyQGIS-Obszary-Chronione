# PyQGIS-Obszary-Chronione
Wtyczka PyQGIS pozwalająca na pobieranie wektorowych warstw obszarów chronionych z serwera WFS GDOŚ w obrębie wskazanej warstwy wejściowej, opcjonalnie powiększonej o bufor.
Dane można dodać do projektu jako warstwy tymczasowe lub zapisać na dysku w formacie Shapefile bądź GeoPackage. Narzędzie umożliwia również wygenerowanie tabeli z listą obszarów chronionych znajdujących się na danym obszarze.
Ikona wtyczki została pobrana z serwisu Flaticon (autor: Umeicon).
